# Security & Privacy

DistroPrep Personal is intentionally a static, local-first application.

## What the app does not collect

- DistroKid passwords
- DistroKid cookies or session tokens
- payment information
- uploaded master files on a remote server
- uploaded artwork on a remote server
- analytics events

Selected files are processed by browser APIs for validation and matching. Metadata drafts can be stored in the browser's local storage when the user explicitly chooses **Save metadata draft**.

## Reporting a security issue

Please open a GitHub issue for non-sensitive security bugs. For a vulnerability that would expose user files or credentials, avoid posting private exploit details publicly; contact the repository owner through their GitHub profile first.
